# Como Contribuir — Equilíbrio

Obrigado pelo interesse em contribuir! Toda ajuda é bem-vinda.

## Formas de Contribuir

### 🐛 Reportar Bugs
Abra uma [Issue](https://github.com/raphaelcsmoraes/equilibrio/issues) descrevendo:
- O que aconteceu
- O que você esperava que acontecesse
- Navegador e dispositivo usado

### 💡 Sugerir Melhorias
Abra uma Issue com a tag `enhancement` descrevendo sua ideia e o problema que ela resolve.

### 🔧 Contribuir com Código

1. Faça um fork do repositório
2. Crie uma branch: `git checkout -b minha-melhoria`
3. Faça suas alterações no `index.html`
4. Teste em diferentes navegadores e tamanhos de tela
5. Abra um Pull Request descrevendo as mudanças

## Princípios do Projeto

- **Zero dependências** — não adicione bibliotecas externas
- **Arquivo único** — tudo em `index.html`
- **Funciona offline** — sem chamadas de API obrigatórias
- **Bilíngue** — qualquer texto novo deve ir para o dicionário em `I18N` (PT e EN)
- **Acessível** — mantenha `aria-label` e navegação por teclado

## Dúvidas Técnicas

Leia a documentação em `docs/` antes de abrir uma Issue. Se ainda tiver dúvidas, sinta-se à vontade para perguntar via Issue.
